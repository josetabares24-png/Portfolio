# José Tabares — portafolio personal (propuesta visual V5)

Rama **solo de preview**. Identidad independiente de todos los proyectos mostrados.

## Dirección de arte

Referente elegido explícitamente: [Eliot Besson](https://www.eliotbesson.com/) por tipografía en gran escala, proyectos que protagonizan la experiencia, navegación cuidada y ficha de trabajo completa. **No es clon**: hay diseño de marca y visuales gráficos propios, sin activos, textos ni diseños originales de Eliot.

- Inicio `/`: portada editorial tipográfica, dos proyectos reales, índice con hover de previsualización, presentación y contacto mediante correo.
- `/proyectos/estaba-en-lisboa/`: caso del proyecto editorial **propio**, claramente diferenciado del portafolio de José.
- `/proyectos/mil-sabores/`: caso de diseño para restauración.
- Las portadas de los dos casos son **artworks gráficos de esta propuesta, no screenshots reales**. Enlaces externos abren las webs reales.
- Todos los precios, métricas, premios, testimonios y clientes ficticios se han omitido.
- Una única dirección artística, sin imágenes generadas por IA, sin maquetas fotográficas de portátiles ni plantas.
- La web internacional aún tiene solo textos en español; versión inglesa se hará tras aprobar dirección visual.
- Las páginas llevan `noindex,nofollow` como protección temporal. No fusionar ni publicar sin aprobación.

## QA

Vite multipágina. Visualizar localmente con `npm run dev`, o servir estáticos desde raíz con `python -m http.server` para revisar HTML/CSS/JS. Comprobar viewport 1440 y 390, menú, accesibilidad de foco, reducido movimiento, enlaces y páginas interiores.

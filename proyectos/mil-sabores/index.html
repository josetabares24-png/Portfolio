UNA WEB QUE INVITA.

Una web de restaurante debe permitir conocer la propuesta, consultar el menú y llegar al local sin perderse.

La estructura prioriza información útil: menú, descripción del negocio, imágenes del producto, ubicación y vías de contacto. La experiencia debe funcionar tanto en escritorio como en móvil.

El trabajo mostrado corresponde al sitio web existente, con una presentación editorial creada específicamente para este portafolio. Puedes abrir el sitio real y comparar el proyecto publicado.
